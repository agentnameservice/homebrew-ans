# ANS Homebrew tap

This tap distributes the [ANS CLI](https://github.com/agentnameservice/ans-sdk-go)
for macOS and Linux.

## Install

```sh
brew tap agentnameservice/ans
brew install ans-cli
```

See the [CLI documentation](https://github.com/agentnameservice/ans-sdk-go#cli-quickstart)
for configuration and usage. The [formula](Formula/ans-cli.rb) is generated by
the Go SDK release process.
